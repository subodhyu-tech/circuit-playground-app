# Tech Explorer

Build a modern, fun 3D technology learning and discovery app for both students and tech enthusiasts. Make it feel polished and energetic, with an immersive 3D-style hero/explorer focused on chips and PC components, searchable technology topics, interactive component breakdowns, AI learning assistant entry point, comparisons, gaming technology, and a curated trending/new-tech updates section. Include clear sections for CPUs/chips, GPUs, motherboards, RAM, storage, networking, gaming hardware, AI and emerging technology. Use a responsive dark modern visual style with vibrant but tasteful accents, strong navigation, and sample content so the experience is immediately usable. Prioritize a compelling frontend experience; structure it so future AI, live updates, and backend content can be added.
